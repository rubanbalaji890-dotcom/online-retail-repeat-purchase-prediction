# Dataset

This folder contains dataset source information for the UCI Online Retail dataset used in the repeat-purchase prediction analysis.

Original dataset size: 541,909 transaction records.

Dataset period: 1 December 2010 – 9 December 2011.

The dataset contains InvoiceNo, StockCode, Description, Quantity, InvoiceDate, UnitPrice, CustomerID and Country.

The analytical workflow removes records with missing CustomerID values, cancelled invoices, duplicate transactions and non-positive Quantity or UnitPrice values.
